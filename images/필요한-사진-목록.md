# 아직 없는 사진

이 이름으로 images/ 폴더에 넣고 `node tools/build.js` 하면 자동으로 들어갑니다.



# 활동 로고 (선택)

`images/logos/` 에 파일을 넣고 `tools/content.ko.js` 해당 활동에 `logo: ["파일명"]` 을 적은 뒤 `node tools/build.js`.
파일이 없으면 로고 칸은 비워진 채로 나옵니다.

- 있음: siggraph.png (ACM SIGGRAPH), gdg.svg (GDG), nvidia.svg (NVIDIA)
- 아직 없음: cucg.png (CUCG Lab), gstar.png (G-STAR), lul.png (LUL), raons.png (라온S), arirang.png (아리랑스쿨) 등
